# Demo assets

This directory is publicly served by Vite. There are no room images here yet; fixture image fields are `null` so the scaffold does not request missing files.

Only add synthetic assets or assets with explicit permission to publish. For each asset, record its filename, creator/source, creation date, license or consent scope, synthetic/real status, and any preprocessing in `docs/ai-disclosures.md` (or a linked asset manifest). An annotated or preprocessed image must not be presented as live detection.

Keep private source captures outside the repository. The ignored `raw-captures/` and `private-captures/` paths are accidental-copy exclusions, not a privacy control. Never put private files under `public/`, even when ignored by Git. Do not include identifying faces, addresses, documents, or location metadata in recording assets.

The existing brand icon remains in `assets/icon.svg` and is unchanged by the scaffold task.
