# Local recording outputs

Store local screen recordings, video edits, still exports, and print-preview PDFs here. Everything in this directory except this README is ignored by Git. Suggested names: `YYYY-MM-DD-take-01.mov`, `YYYY-MM-DD-plan-preview.pdf`, and `YYYY-MM-DD-demo-review.mp4`.

The app is not ready to record yet. Complete the gates in [`docs/video-shot-list.md`](../docs/video-shot-list.md), run the required checks, reset the synthetic state, and rehearse the actual journey first. Use ordinary browser/system recording tools; no native capture application is part of this project.

Review the full frame and audio for private data, browser/account identifiers, messages, addresses, and unapproved faces before sharing. Keep private originals outside the repository. An ignored directory does not provide encryption or access control.

Track publishable asset provenance and real assistance in `docs/ai-disclosures.md`. Keep synthetic examples, preprocessed assets, computed results, and family-reported status clearly identified in the video. Uploading or publishing is a separate action requiring authorization.
