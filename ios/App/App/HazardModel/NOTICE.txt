FixList local visible-object review detector

Model: Ultralytics YOLO-World v2 small (yolov8s-worldv2.pt).
Fixed vocabulary, 640 x 640 RGB, fp16 ML Program + class-wise Core ML NMS.

Text embeddings are baked offline using OpenAI CLIP ViT-B/32 (MIT code and
weights; https://github.com/openai/CLIP). See LICENSE-OpenAI-CLIP-MIT.txt.
No text encoder runs on the phone.
Core ML conversion uses coremltools (BSD-3-Clause). Runtime inference uses
Apple Vision/Core ML; no Ultralytics Python runtime is installed in the app.
The AGPL applies to this export; embedding it does not make it MIT-licensed.

Reproduction and local changes: scan/ondevice/export_detector.py,
publish_detector.py, detector-rules.json, and
ios/App/App/FixListHazardsPlugin.swift. The historic HazardImageEncoder and
hazard-prompts resource names are retained for Xcode compatibility; they now
contain an object detector and rule manifest. Content pins are in the manifest.
No private photos or household information are bundled in this model.

Unverified experimental object proposals only. Object presence, lower-frame
geometry, and no grab bar detected do not establish a hazard, a missing bar,
support needs, or safety. Confidence is not a calibrated hazard probability.
Users review and decide; no checklist is answered automatically.
