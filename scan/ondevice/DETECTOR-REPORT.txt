- Fixed vocabulary is baked into the model; no text encoder or network inference
  runs on the phone. Native engine is yolo-world-object-rules.
- Vision .scaleFill matches the full-image Python resize. Vision class confidence
  is multiplied by observation confidence; using only the class score inflated
  weak detections. The macOS parity harness caught and verified this correction.
- Native box points bypass only the old 3x3-grid and 0.7 location restrictions.
  Strict photo bounds, status, content identity and threshold checks remain.

Thresholds and geometric rules
- rug / floor mat / runner rug: >=0.30. Box centre y>=0.45, bottom y>=0.65.
  Emits rug-check at >=0.30. This detects presence, not a curled/slipping edge.
- electrical cord / extension cord / power strip: >=0.25. Centre y>=0.60,
  bottom y>=0.72, normalized box width>=0.08, and pixel width/height>=1.4.
  Emits cord-check at >=0.25. Lower frame is only a floor-location heuristic.
- shoe/clothes/toy/book: >=0.30; bag/cardboard box: >=0.35. A stairs box >=0.25
  must overlap >=60% of the object's box area. Emits stair-clutter-check using
  object confidence, per-item threshold 0.30.
- toilet >=0.45 or shower >=0.50; bathtub >=0.50 additionally needs a toilet
  or shower detection >=0.15. Any grab bar >=0.12 anywhere suppresses the
  support prompt. Emits bathroom-support-check at >=0.45.
- All rule candidates except bar suppression need normalized box area>=0.002.
- handrail-check, stair-lighting-check, night-lighting-check and
  shower-surface-check always score 0; threshold 1 means abstain.
- Other vocabulary classes provide context only. Scores are development-selected
  heuristics, not calibrated probabilities or independently validated thresholds.

Rule details
- Floor class thresholds: shoe >=0.30; clothes >=0.30; cardboard box >=0.35;
  toy >=0.35; bag >=0.40; book >=0.40.

- Use the clipped normalized saved-photo box. Its area must be >=0.002 and
  its bottom must be >=0.72 of frame height (top-left y increases downwards).
- Furniture context: table, desk, sofa, chair, bed, cabinet, kitchen counter
  and kitchen island; confidence >=0.25 and area >=0.002.
- Suppress a candidate if >=50% of its own area lies inside ANY such furniture
  box AND the candidate's bottom is strictly above that furniture's bottom.
  At/below the furniture bottom, that furniture box does not suppress it.
  This retains floor objects under a table whose projection overlaps the box.
- Emit confidence and saved-photo pixel centre of the highest-confidence
  qualifying object. A stronger suppressed object does not hide a weaker
  qualifying object. ONDEVICE_THRESHOLDS['floor-clutter-check'] is 0.30.
