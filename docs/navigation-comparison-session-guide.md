# FixList navigation comparison: session guide

**Purpose.** See which of two layouts, three tabs or four tabs, is easier for an older adult to find their way around. This is a small, informal comparison. It is not a validated usability study, and it says nothing about home safety.

**About the app.** FixList is a local demo. All household data is fictional ("Fictional Maple House", resident Margaret, helper Sam, volunteers Alex and Jordan). Nothing is sent anywhere and nobody is contacted. The participant is testing the app, not being tested.

The layouts:

- **Three tabs:** Home / Rooms / Requests. The fix list appears directly on Home, with "Open full fix list".
- **Four tabs:** Home / Rooms / Fix list / Requests.
- **Current** (optional reference, show last): Home / Check / Plan / Help / More.

In the three- and four-tab layouts, the header button **Account and settings** holds person switching, language, access, the printable report, About, the guide and Reset demo. The header's help button is labelled **Using this screen**. "Find local help" is under Requests and the 3D "Room scan" is under Rooms.

## Consent and privacy

- Ask for verbal permission before you start. Say they can stop or skip anything at any time.
- Do not write down names or personal details. Use a code such as P1 or P2.
- Take notes on paper. Do not record video of anyone's face or home. If you want a screen recording, get permission first and capture the screen only.

## Setup checklist (repeat before each layout)

1. **Reset:** Account and settings (or More in the current layout) → Reset demo → Yes, reset FixList. The app returns to "Choose your language". Reset also clears the layout choice.
2. Choose **English** → **Margaret** → **Skip guide**.
3. **Pick the layout:** Account and settings / More → "Navigation layout (prototype)". In a browser you can instead open the app URL with `?nav=three` or `?nav=four`.
4. **Prepare task 5 with the hallway cord.** Don't use the rug: the participant confirms and asks for help with the rug in tasks 3 and 4.
   - As Margaret: Rooms (Check) → Sample hallway → Yes → Confirm this is something to fix.
   - Open the fix list (Home in three tabs, Fix list in four tabs, Plan in current) → "Ask for help" on **Review the cord route** → tick Room name → Continue → Choose Alex → Invite Alex.
   - Switch to Alex (Account and settings → Switch person → Alex; in the current layout tap the person chip). Open the cord task → Accept invitation → type a time → Propose a time.
   - Switch to Margaret → open the cord request (Requests) → Agree to this time.
   - Switch to Alex → open the cord task → type a short update → Post an update → Report done.
   - Switch back to **Margaret** and go to Home.
5. Alternate which layout goes first between participants (P1: three then four; P2: four then three; and so on).
6. Have the recording sheet, a pen and a stopwatch ready.

**Note:** after step 4, Home's "Your next step" card reads "Review a completion report". That card is a shortcut for task 5, so record whether the participant used it.

## Script to read aloud

> "Thanks for helping. This is a practice app with made-up information, so nothing you tap will affect anything real, and nobody will be contacted. We're testing the app, not you. If something is confusing, that's the app's fault, and that is exactly what I want to find out. Please say out loud what you're thinking or looking for. You can stop at any time. Pretend you are Margaret, who lives in this house."

If the participant gets stuck, wait a bit, then give a general hint such as "What do you think that button does?" Don't name a tab. Mark the task "with a hint". If they are still stuck after about another minute, mark it "not completed" and move on. (The one-minute cutoff is a practical suggestion, not a project rule.)

If the family helper is present, let the older adult use the app. Note any time the helper steps in.

## Task prompts

Read each one aloud. Don't name any tab or button.

1. "Find the stairs in the house."
2. "There's a question about the rug in the living room. Find it and tell me what you see."
3. "You agree the rug needs fixing. Tell the app that."
4. "Ask for help getting the rug fixed."
5. "A volunteer says they finished a job. Look at what they reported and decide whether it's really done."

## What to note for each task

- **Result:** completed without help (C), completed with a hint (H), or not completed (N).
- **Wrong turns:** taps that went somewhere unhelpful.
- **Rough time:** the stopwatch is fine.
- **Looked first:** where their eyes or finger went first.
- **Quotes:** exact words, with no names.

After both layouts, ask:

1. "Which one felt easier, and why?"
2. "Was anything confusing?"

Optionally, show the current layout last and ask whether it feels easier or harder than the other two.

## Summarizing afterwards

1. For each task and layout, count how many participants finished without help, with a hint, or not at all. Add up the wrong turns and note typical times.
2. Look for patterns. Did people look in the same wrong place first? Did the same task cause trouble in both layouts? Which comments came up more than once?
3. Keep the raw notes and sheets.

**Remember:** with one to three participants, this is directional evidence only. It can point to things worth fixing or testing further, but it can't show that either layout is better. A scripted run on 2026-10-18 completed all five tasks in both layouts, in Chromium and in the iOS Simulator. The only path difference was that "Ask for help" is reachable directly from Home in the three-tab layout (1 tap versus 2). That says nothing about how real people find their way, and that is what these sessions are for.
